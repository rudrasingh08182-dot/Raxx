The elimination method involves removing one variable to solve for the other. 
Steps:
1. Multiply equations by constants to make the coefficients of one variable equal.
2. Add or subtract the equations to eliminate that variable.
3. Solve the resulting single-variable equation.
4. Substitute the value back into an original equation to find the second variable.

If the process leads to a true statement (e.g., $0=0$), there are infinitely many solutions. If it leads to a false statement (e.g., $0=9$), there is no solution.
