1. Solve by substitution: $x + y = 14$ and $x - y = 4$.
2. Solve by elimination: $3x + 4y = 10$ and $2x - 2y = 2$.
3. Determine if the following are consistent or inconsistent: $3x + 2y = 5$ and $2x - 3y = 7$.
4. A fraction becomes $\frac{9}{11}$ if 2 is added to both numerator and denominator. If 3 is added to both, it becomes $\frac{5}{6}$. Find the fraction.
