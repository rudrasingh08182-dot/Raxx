1. **AP Definition:** A sequence where $a_{k+1} - a_k = d$ (constant).
2. **General Form:** $a, a+d, a+2d, \dots$
3. **nth Term:** $a_n = a + (n - 1)d$
4. **Sum of n terms:** $S_n = \frac{n}{2} [2a + (n - 1)d]$ or $S_n = \frac{n}{2} (a + l)$
5. **Arithmetic Mean:** If $a, b, c$ are in AP, then $b = \frac{a+c}{2}$.
