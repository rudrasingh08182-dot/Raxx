Example: Find the 10th term of the AP: 2, 7, 12, ...
Solution: Here, $a = 2$, $d = 7 - 2 = 5$, and $n = 10$.
Using $a_n = a + (n - 1)d$:
$a_{10} = 2 + (10 - 1) \times 5 = 2 + 45 = 47$.

Example: Which term of the AP: 21, 18, 15, ... is -81?
Solution: $a = 21$, $d = -3$, $a_n = -81$.
$-81 = 21 + (n - 1)(-3)$
$-102 = (n - 1)(-3) \implies n - 1 = 34 \implies n = 35$.
