An Arithmetic Progression (AP) is a list of numbers in which each term is obtained by adding a fixed number to the preceding term, except for the first term. This fixed number is called the **common difference** ($d$), which can be positive, negative, or zero.

If the first term is $a$ and the common difference is $d$, the AP is represented as:
$a, a + d, a + 2d, a + 3d, \dots$

- **Finite AP:** An AP with a finite number of terms (has a last term).
- **Infinite AP:** An AP that does not have a last term.

For any AP $a_1, a_2, \dots, a_n$, the common difference is given by:
$d = a_{k+1} - a_k$
