To find the distance between any two points $P(x_1, y_1)$ and $Q(x_2, y_2)$, we use the Pythagoras theorem. The distance formula is given by:

$PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$

Note that since distance is always non-negative, we take only the positive square root. 

**Remarks:**
1. The distance of a point $P(x, y)$ from the origin $O(0, 0)$ is given by $OP = \sqrt{x^2 + y^2}$.
2. We can also write $PQ = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$.
