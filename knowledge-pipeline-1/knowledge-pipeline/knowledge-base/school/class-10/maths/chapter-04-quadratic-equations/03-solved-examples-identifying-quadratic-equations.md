Check whether the following are quadratic equations:
(i) $(x - 2)^2 + 1 = 2x - 3$ 
LHS: $x^2 - 4x + 4 + 1 = x^2 - 4x + 5$. Rewriting: $x^2 - 6x + 8 = 0$. This is a quadratic equation.

(ii) $x(x + 1) + 8 = (x + 2)(x - 2)$
LHS: $x^2 + x + 8$. RHS: $x^2 - 4$. Simplifying: $x + 12 = 0$. This is not a quadratic equation as the $x^2$ terms cancel out.

(iii) $x(2x + 3) = x^2 + 1$
Simplifying: $2x^2 + 3x = x^2 + 1 \implies x^2 + 3x - 1 = 0$. This is a quadratic equation.

(iv) $(x + 2)^3 = x^3 - 4$
Simplifying: $x^3 + 6x^2 + 12x + 8 = x^3 - 4 \implies 6x^2 + 12x + 12 = 0$. This is a quadratic equation.
