The median is the middle-most observation. For grouped data, we use the cumulative frequency distribution. The median class is the class whose cumulative frequency is greater than (and nearest to) $\frac{n}{2}$. The median is calculated as:

$$\text{Median} = l + \left( \frac{\frac{n}{2} - cf}{f} \right) \times h$$

Where:
- $l$ = lower limit of the median class
- $n$ = total number of observations
- $cf$ = cumulative frequency of the class preceding the median class
- $f$ = frequency of the median class
- $h$ = class size
