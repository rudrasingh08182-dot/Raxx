Trigonometric identities are equations involving trigonometric ratios that are true for all values of the angles involved:

1. $\cos^2 A + \sin^2 A = 1$
2. $1 + \tan^2 A = \sec^2 A$ (for $0^\circ \le A < 90^\circ$)
3. $\cot^2 A + 1 = \text{cosec}^2 A$ (for $0^\circ < A \le 90^\circ$)
