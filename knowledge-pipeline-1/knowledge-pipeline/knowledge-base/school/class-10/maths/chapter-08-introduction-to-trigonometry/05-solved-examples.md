Example: Given $\tan A = 4/3$, find other ratios.
Solution: Since $\tan A = BC/AB = 4/3$, let $BC = 4k$ and $AB = 3k$. By Pythagoras theorem, $AC = \sqrt{(4k)^2 + (3k)^2} = 5k$. 
Thus, $\sin A = 4k/5k = 4/5$ and $\cos A = 3k/5k = 3/5$.
