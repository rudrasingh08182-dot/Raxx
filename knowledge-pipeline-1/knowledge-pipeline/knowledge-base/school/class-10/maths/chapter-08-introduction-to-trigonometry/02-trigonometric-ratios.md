In a right triangle $ABC$ with $\angle CAB$ (or $\angle A$) as an acute angle, the trigonometric ratios are defined as:

- $\sin A = \frac{\text{side opposite to } A}{\text{hypotenuse}} = \frac{BC}{AC}$
- $\cos A = \frac{\text{side adjacent to } A}{\text{hypotenuse}} = \frac{AB}{AC}$
- $\tan A = \frac{\text{side opposite to } A}{\text{side adjacent to } A} = \frac{BC}{AB}$
- $\text{cosec } A = \frac{1}{\sin A} = \frac{AC}{BC}$
- $\sec A = \frac{1}{\cos A} = \frac{AC}{AB}$
- $\cot A = \frac{1}{\tan A} = \frac{AB}{BC}$

Note: $\tan A = \frac{\sin A}{\cos A}$ and $\cot A = \frac{\cos A}{\sin A}$.
