1. In $\triangle ABC$, right-angled at $B$, $AB = 24$ cm, $BC = 7$ cm. Determine $\sin A, \cos A$.
2. If $15 \cot A = 8$, find $\sin A$ and $\sec A$.
3. Evaluate: $\sin 60^\circ \cos 30^\circ + \sin 30^\circ \cos 60^\circ$.
4. Prove: $(\text{cosec } \theta - \cot \theta)^2 = \frac{1 - \cos \theta}{1 + \cos \theta}$.
