For any event $E$, the event 'not $E$' is denoted by $\overline{E}$. These are called complementary events. The relationship between them is given by:

$P(E) + P(\overline{E}) = 1$

This implies $P(\overline{E}) = 1 - P(E)$. 

Furthermore, the probability of an event $P(E)$ always satisfies the condition:

$0 \le P(E) \le 1$

- If an event is impossible, its probability is 0.
- If an event is certain to occur, its probability is 1.
