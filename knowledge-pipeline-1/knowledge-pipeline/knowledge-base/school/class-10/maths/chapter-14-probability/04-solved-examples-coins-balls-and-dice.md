### Example 1: Coin Toss
For a single toss, $P(\text{head}) = 1/2$ and $P(\text{tail}) = 1/2$.

### Example 2: Drawing Marbles
A bag contains 3 blue, 2 white, and 4 red marbles. Total outcomes = 9.
- $P(\text{white}) = 2/9$
- $P(\text{blue}) = 3/9 = 1/3$
- $P(\text{red}) = 4/9$

### Example 3: Throwing a Die
For a single throw (outcomes 1, 2, 3, 4, 5, 6):
- $P(\text{number} > 4) = P(5, 6) = 2/6 = 1/3$
- $P(\text{number} \le 4) = P(1, 2, 3, 4) = 4/6 = 2/3$
