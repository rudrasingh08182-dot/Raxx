Hence, he inferred that the $O_2$ evolved by the green plant comes from $H_2O$, not from carbon dioxide. This was later proved by using radioisotopic techniques. The correct equation, that would represent the overall process of photosynthesis is therefore:

$6CO_2 + 12H_2O \xrightarrow{Light} C_6H_{12}O_6 + 6H_2O + 6O_2$

where $C_6H_{12}O_6$ represents glucose. The $O_2$ released is from water; this was proved using radio isotope techniques. Note that this is not a single step process.
