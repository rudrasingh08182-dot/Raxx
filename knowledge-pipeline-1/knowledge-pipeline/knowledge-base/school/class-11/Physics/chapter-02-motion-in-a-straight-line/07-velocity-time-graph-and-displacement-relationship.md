(d) An object is moving in positive direction till time $t_1$, and then turns back with the same negative acceleration. An interesting feature of a velocity-time graph for any moving object is that the area under the curve represents the displacement over a given time interval. A general proof of this statement requires use of calculus. We can, however, see that it is true for the simple case of an object moving with constant velocity $u$.
