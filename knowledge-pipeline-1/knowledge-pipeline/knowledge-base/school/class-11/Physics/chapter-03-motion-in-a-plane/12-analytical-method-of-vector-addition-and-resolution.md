### MOTION IN A PLANE

Let $\mathbf{R}$ be the sum of vectors $\mathbf{A}$ and $\mathbf{B}$. We have:
$\mathbf{R} = \mathbf{A} + \mathbf{B}$
$\mathbf{R} = (A_x \hat{i} + A_y \hat{j}) + (B_x \hat{i} + B_y \hat{j})$ (3.19a)

Since vectors obey the commutative and associative laws, we can arrange and regroup the vectors in Eq. (3.19a) as convenient to us:
$\mathbf{R} = (A_x + B_x) \hat{i} + (A_y + B_y) \hat{j}$ (3.19b)

Since $\mathbf{R} = R_x \hat{i} + R_y \hat{j}$ (3.20), we have:
$R_x = A_x + B_x, R_y = A_y + B_y$ (3.21)

Thus, each component of the resultant vector $\mathbf{R}$ is the sum of the corresponding components of $\mathbf{A}$ and $\mathbf{B}$. In three dimensions, we have:
$\mathbf{A} = A_x \hat{i} + A_y \hat{j} + A_z \hat{k}$
$\mathbf{B} = B_x \hat{i} + B_y \hat{j} + B_z \hat{k}$
$\mathbf{R} = \mathbf{A} + \mathbf{B} = R_x \hat{i} + R_y \hat{j} + R_z \hat{k}$
with $R_x = A_x + B_x$, $R_y = A_y + B_y$, $R_z = A_z + B_z$ (3.22)

This method can be extended to addition and subtraction of any number of vectors. For example, if vectors $\mathbf{a}$, $\mathbf{b}$ and $\mathbf{c}$ are given as:
$\mathbf{a} = a_x \hat{i} + a_y \hat{j} + a_z \hat{k}$
$\mathbf{b} = b_x \hat{i} + b_y \hat{j} + b_z \hat{k}$
$\mathbf{c} = c_x \hat{i} + c_y \hat{j} + c_z \hat{k}$ (3.23a)

then, a vector $\mathbf{T} = \mathbf{a} + \mathbf{b} - \mathbf{c}$ has components:
$T_x = a_x + b_x - c_x$
$T_y = a_y + b_y - c_y$
$T_z = a_z + b_z - c_z$ (3.23b)

**Example 3.2** Find the magnitude and direction of the resultant of two vectors $\mathbf{A}$ and $\mathbf{B}$ in terms of their magnitudes and angle $\theta$ between them.

**Fig. 3.9 (d)** A vector $\mathbf{A}$ resolved into components along x-, y-, and z-axes.
* Note that angles $\alpha$, $\beta$, and $\gamma$ are angles in space. They are between pairs of lines, which are not coplanar. So far we have considered a vector lying in an x-y plane. The same procedure can be used to resolve a general vector $\mathbf{A}$ into three components along x-, y-, and z-axes in three dimensions. If $\alpha$, $\beta$, and $\gamma$ are the angles between $\mathbf{A}$ and the x-, y-, and z-axes, respectively [Fig. 3.9(d)], we have:
$A_x = A \cos \alpha, A_y = A \cos \beta, A_z = A \cos \gamma$ (3.16a)

In general, we have:
$\mathbf{A} = A_x \hat{i} + A_y \hat{j} + A_z \hat{k}$ (3.16b)

The magnitude of vector $\mathbf{A}$ is:
$A = \sqrt{A_x^2 + A_y^2 + A_z^2}$ (3.16c)

A position vector $\mathbf{r}$ can be expressed as:
$\mathbf{r} = x \hat{i} + y \hat{j} + z \hat{k}$ (3.17)
where $x$, $y$, and $z$ are the components of $\mathbf{r}$ along x-, y-, z-axes, respectively.
