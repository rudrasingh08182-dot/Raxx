In The Paradox of Fractional Oxidation Number
Sometimes, we come across with certain compounds in which the oxidation number of a particular element in the compound is in fraction. Examples are:
$C_3O_2$ [where oxidation number of carbon is (4/3)], $Br_3O_8$ [where oxidation number of bromine is (16/3)] and $Na_2S_4O_6$ (where oxidation number of sulphur is 2.5).

We know that the idea of fractional oxidation number is unconvincing to us, because electrons are never shared/transferred in fraction. Actually this fractional oxidation state is the average oxidation state of the element under examination and the structural parameters reveal that the element for whom fractional oxidation state is realised is present in different oxidation states.
