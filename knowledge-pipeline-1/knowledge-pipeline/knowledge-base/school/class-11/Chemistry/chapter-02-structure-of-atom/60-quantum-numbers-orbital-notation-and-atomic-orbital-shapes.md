### Problem 2.18
Using s, p, d, f notations, describe the orbital with the following quantum numbers:
(a) n = 2, l = 1, (b) n = 4, l = 0, (c) n = 5, l = 3, (d) n = 3, l = 2

**Solution**

| n | l | orbital |
|---|---|---|
| a) 2 | 1 | 2p |
| b) 4 | 0 | 4s |
| c) 5 | 3 | 5f |
| d) 3 | 2 | 3d |

### 2.6.2 Shapes of atomic orbitals
The orbital wave function or $\psi$ for an electron in an atom has no physical meaning. It is simply a mathematical function of the coordinates of the electron. However, for different orbitals the plots of corresponding wave functions as a function of r (the distance from the nucleus) are different. Fig. 2.12(a) gives such plots for 1s (n = 1, l = 0) and 2s (n = 2, l = 0) orbitals.
