The Henderson-Hasselbalch equation is given by:

$pH = pK_a + \log \frac{[Salt]}{[Acid]}$

In the equation, if the concentration of $[A^-]$ is equal to the concentration of $[HA]$, then $pH = pK_a$ because the value of $\log 1$ is zero. Thus, if we take the molar concentration of acid and salt (conjugate base) the same, the pH of the buffer solution will be equal to the $pK_a$ of the acid. So, for preparing the buffer solution of the required pH, we select that acid whose $pK_a$ is close to the required pH. For acetic acid, the $pK_a$ value is 4.76; therefore, the pH of the buffer solution formed by acetic acid and sodium acetate taken in equal molar concentration will be around 4.76.

A similar analysis of a buffer made with a weak base and its conjugate acid leads to the result:

$pOH = pK_b + \log \frac{[Conjugate acid, BH^+]}{[Base, B]}$ (6.41)

The pH of the buffer solution can be calculated by using the equation $pH + pOH = 14$. We know that $pH + pOH = pK_w$ and $pK_a + pK_b = pK_w$. On putting these values in equation (6.41), it takes the form as follows:

$pH = pK_a + \log \frac{[Conjugate acid, BH^+]}{[Base, B]}$ (6.42)

If the molar concentration of the base and its conjugate acid (cation) is the same, then the pH of the buffer solution will be the same as $pK_a$ for the base. The $pK_a$ value for ammonia is 9.25; therefore, a buffer of pH close to 9.25 can be obtained by taking an ammonia solution and ammonium chloride solution of the same molar concentration. For a buffer solution formed by ammonium chloride and ammonium hydroxide, equation (6.42) becomes:

$pH = 9.25 + \log \frac{[Conjugate acid, BH^+]}{[Base, B]}$
