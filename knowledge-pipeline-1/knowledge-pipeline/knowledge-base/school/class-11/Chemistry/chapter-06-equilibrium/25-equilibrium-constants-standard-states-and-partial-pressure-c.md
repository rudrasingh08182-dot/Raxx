For the reactions, $H_{2(g)} + I_{2(g)} \rightleftharpoons 2HI$, $K_c$ and $K_p$ have no unit. $N_2O_{4(g)} \rightleftharpoons 2NO_2(g)$, $K_c$ has unit $mol/L$ and $K_p$ has unit $bar$.

Equilibrium constants can also be expressed as dimensionless quantities if the standard state of reactants and products are specified. For a pure gas, the standard state is $1 bar$. Therefore a pressure of $4 bar$ in standard state can be expressed as $4 bar / 1 bar = 4$, which is a dimensionless number. Standard state ($c^0$) for a solute is $1 molar$ solution and all concentrations can be measured with respect to it. The numerical value of equilibrium constant depends on the standard state chosen. Thus, in this system both $K_p$ and $K_c$ are dimensionless quantities but have different numerical values due to different standard states.
