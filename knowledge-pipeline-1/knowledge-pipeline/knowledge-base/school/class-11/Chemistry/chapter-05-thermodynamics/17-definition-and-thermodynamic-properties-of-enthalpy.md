Let us represent the initial state by subscript 1 and final state by 2. We can rewrite the above equation as:

$U_2 - U_1 = q_p - p(V_2 - V_1)$

On rearranging, we get:

$q_p = (U_2 + pV_2) - (U_1 + pV_1)$ (5.6)

Now we can define another thermodynamic function, the enthalpy $H$ [Greek word enthalpien, to warm or heat content] as:

$H = U + pV$ (5.7)

So, equation (5.6) becomes:

$q_p = H_2 - H_1 = \Delta H$

Although $q$ is a path dependent function, $H$ is a state function because it depends on $U$, $p$ and $V$, all of which are state functions. Therefore, $\Delta H$ is independent of path. Hence, $q_p$ is also independent of path. For finite changes at constant pressure, we can write equation 5.7 as:

$\Delta H = \Delta U + \Delta pV$

Since $p$ is constant, we can write:

$\Delta H = \Delta U + p\Delta V$ (5.8)

It is important to note that when heat is absorbed by the system at constant pressure, we are actually measuring changes in the enthalpy.
