Solution: Consider $g : \{a, b, c\} \to \{1, 2, 3\}$ as $g(a) = 1$, $g(b) = 2$ and $g(c) = 3$. It is easy to verify that the composite $g \circ f = I_X$ is the identity function on $X$ and the composite $f \circ g = I_Y$ is the identity function on $Y$.

Remark: The interesting fact is that the result mentioned in the above example is true for an arbitrary one-one and onto function $f : X \to Y$. Not only this, even the converse is also true, i.e., if $f : X \to Y$ is a function such that there exists a function $g : Y \to X$ such that $g \circ f = I_X$ and $f \circ g = I_Y$, then $f$ must be one-one and onto.
