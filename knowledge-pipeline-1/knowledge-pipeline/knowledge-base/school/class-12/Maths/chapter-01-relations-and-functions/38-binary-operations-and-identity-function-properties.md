Since 1 is the identity for the desired binary operation $*$, $*(1, 1) = 1$, $*(1, 2) = 2$, $*(2, 1) = 2$ and the only choice left is for the pair $(2, 2)$. Since 2 is the inverse of 2, i.e., $*(2, 2)$ must be equal to 1. Thus, the number of desired binary operation is only one.

**Example 50**
Consider the identity function $I_N : N \to N$ defined as $I_N(x) = x$ $\forall x \in N$. Show that although $I_N$ is onto but $I_N + I_N : N \to N$ defined as $(I_N + I_N)(x) = I_N(x) + I_N(x) = x + x = 2x$ is not onto.

**Solution**
Clearly $I_N$ is onto. But $I_N + I_N$ is not onto, as we can find an element 3 in the co-domain $N$ such that there does not exist any $x$ in the domain $N$ with $(I_N + I_N)(x) = 2x = 3$.
