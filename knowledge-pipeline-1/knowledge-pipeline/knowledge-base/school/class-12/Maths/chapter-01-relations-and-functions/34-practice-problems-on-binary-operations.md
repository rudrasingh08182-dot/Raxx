6. Let $*$ be the binary operation on $\mathbb{N}$ given by $a * b = \text{L.C.M. of } a \text{ and } b$. Find

(iv) Find the identity of $*$ in $\mathbb{N}$

8. Let $*$ be the binary operation on $\mathbb{N}$ defined by $a * b = \text{H.C.F. of } a \text{ and } b$. Is $*$ commutative? Is $*$ associative? Does there exist identity for this binary operation on $\mathbb{N}$?

9. Let $*$ be a binary operation on the set $\mathbb{Q}$ of rational numbers as follows:
(i) $a * b = a - b$
(ii) $a * b = a^2 + b^2$
(iii) $a * b = a + ab$
(iv) $a * b = (a - b)^2$
(v) $a * b = \frac{ab}{4}$
(vi) $a * b = ab^2$

10. Find which of the operations given above has identity.
