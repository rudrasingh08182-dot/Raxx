Example 48: Show that the function $f$ given by $f(x) = \tan^{-1}(\sin x + \cos x)$, $x > 0$ is always an increasing function in $(0, \frac{\pi}{4})$.

Solution: We have $f(x) = \tan^{-1}(\sin x + \cos x)$, $x > 0$.
Therefore $f'(x) = \frac{1}{1 + (\sin x + \cos x)^2} (\cos x - \sin x) = \frac{\cos x - \sin x}{2 + \sin 2x}$ (on simplification).
Note that $2 + \sin 2x > 0$ for all $x$ in $(0, \frac{\pi}{4})$.
Therefore $f'(x) > 0$ if $\cos x - \sin x > 0$ or $f'(x) > 0$ if $\cos x > \sin x$ or $\cot x > 1$.
Now $\cot x > 1$ if $\tan x < 1$, i.e., if $0 < x < \frac{\pi}{4}$.
Thus $f'(x) > 0$ in $(0, \frac{\pi}{4})$.
Hence $f$ is an increasing function in $(0, \frac{\pi}{4})$.
