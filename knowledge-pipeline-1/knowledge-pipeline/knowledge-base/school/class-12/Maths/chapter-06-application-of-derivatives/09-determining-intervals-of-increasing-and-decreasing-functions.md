Example 10: Find the intervals in which the function $f$ given by $f(x) = x^2 - 4x + 6$ is (a) increasing (b) decreasing.

Solution: We have $f(x) = x^2 - 4x + 6$ or $f'(x) = 2x - 4$. Therefore, $f'(x) = 0$ gives $x = 2$. Now the point $x = 2$ divides the real line into two disjoint intervals namely, $(-\infty, 2)$ and $(2, \infty)$ (Fig 6.3). In the interval $(-\infty, 2)$, $f'(x) = 2x - 4 < 0$. Therefore, $f$ is decreasing in this interval. Also, in the interval $(2, \infty)$, $f'(x) > 0$ and so the function $f$ is increasing in this interval.

Example 11: Find the intervals in which the function $f$ given by $f(x) = 4x^3 - 6x^2 - 72x + 30$ is (a) increasing (b) decreasing.

Solution: We have $f(x) = 4x^3 - 6x^2 - 72x + 30$ or $f'(x) = 12x^2 - 12x - 72 = 12(x^2 - x - 6) = 12(x - 3)(x + 2)$. Therefore, $f'(x) = 0$ gives $x = -2, 3$. The points $x = -2$ and $x = 3$ divide the real line into three disjoint intervals, namely, $(-\infty, -2)$, $(-2, 3)$ and $(3, \infty)$.
