2. (i) $\sin^{-1} (-x) = -\sin^{-1} x, x \in [-1, 1]$
(ii) $\tan^{-1} (-x) = -\tan^{-1} x, x \in R$
(iii) $\csc^{-1} (-x) = -\csc^{-1} x, |x| \geq 1$

Let $\sin^{-1} (-x) = y$, i.e., $-x = \sin y$ so that $x = -\sin y$, i.e., $x = \sin(-y)$. Hence $\sin^{-1} x = -y = -\sin^{-1}(-x)$. Therefore $\sin^{-1}(-x) = -\sin^{-1} x$. Similarly, we can prove the other parts.

3. (i) $\cos^{-1} (-x) = \pi - \cos^{-1} x, x \in [-1, 1]$
(ii) $\sec^{-1} (-x) = \pi - \sec^{-1} x, |x| \geq 1$
(iii) $\cot^{-1} (-x) = \pi - \cot^{-1} x, x \in R$

Let $\cos^{-1} (-x) = y$ i.e., $-x = \cos y$ so that $x = -\cos y = \cos(\pi - y)$. Therefore $\cos^{-1} x = \pi - y = \pi - \cos^{-1}(-x)$. Hence $\cos^{-1}(-x) = \pi - \cos^{-1} x$. Similarly, we can prove the other parts.

4. (i) $\sin^{-1} x + \cos^{-1} x = \frac{\pi}{2}, x \in [-1, 1]$
(ii) $\tan^{-1} x + \cot^{-1} x = \frac{\pi}{2}, x \in R$
(iii) $\csc^{-1} x + \sec^{-1} x = \frac{\pi}{2}, |x| \geq 1$

Let $\sin^{-1} x = y$. Then $x = \sin y = \cos(\frac{\pi}{2} - y)$. Therefore $\cos^{-1} x = \frac{\pi}{2} - y = \frac{\pi}{2} - \sin^{-1} x$. Hence $\sin^{-1} x + \cos^{-1} x = \frac{\pi}{2}$. Similarly, we can prove the other parts.

5. (i) $\tan^{-1} x + \tan^{-1} y = \tan^{-1} \frac{x + y}{1 - xy}, xy < 1$
(ii) $\tan^{-1} x - \tan^{-1} y = \tan^{-1} \frac{x - y}{1 + xy}, xy > -1$
(iii) $\tan^{-1} x + \tan^{-1} y = \pi + \tan^{-1} \frac{x + y}{1 - xy}, xy > 1; x, y > 0$

Let $\tan^{-1} x = \theta$ and $\tan^{-1} y = \phi$. Then $x = \tan \theta, y = \tan \phi$. Now $\tan(\theta + \phi) = \frac{\tan \theta + \tan \phi}{1 - \tan \theta \tan \phi} = \frac{x + y}{1 - xy}$. This gives $\theta + \phi = \tan^{-1} \frac{x + y}{1 - xy}$. Hence $\tan^{-1} x + \tan^{-1} y = \tan^{-1} \frac{x + y}{1 - xy}$. In the above result, if we replace $y$ by $-y$, we get the second result and by replacing $y$ by $x$, we get the third result as given below.

6. (i) $2\tan^{-1} x = \sin^{-1} \frac{2x}{1 + x^2}, |x| \leq 1$
(ii) $2\tan^{-1} x = \cos^{-1} \frac{1 - x^2}{1 + x^2}, x \geq 0$
(iii) $2\tan^{-1} x = \tan^{-1} \frac{2x}{1 - x^2}, -1 < x < 1$

Let $\tan^{-1} x = y$, then $x = \tan y$. Now $\sin^{-1} \frac{2x}{1 + x^2} = \sin^{-1} \frac{2 \tan y}{1 + \tan^2 y} = \sin^{-1}(\sin 2y) = 2y = 2\tan^{-1} x$.
