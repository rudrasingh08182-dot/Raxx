**Example 7** Prove that $\tan^{-1} x + \tan^{-1} \frac{2x}{1-x^2} = \tan^{-1} \frac{3x-x^3}{1-3x^2}$, $|x| < \frac{1}{\sqrt{3}}$

**Solution** Let $x = \tan \theta$. Then $\theta = \tan^{-1} x$. We have

R.H.S. = $\tan^{-1} \left( \frac{3\tan \theta - \tan^3 \theta}{1 - 3\tan^2 \theta} \right) = \tan^{-1} (\tan 3\theta) = 3\theta = 3\tan^{-1} x = \tan^{-1} x + 2\tan^{-1} x = \tan^{-1} x + \tan^{-1} \frac{2x}{1-x^2} = \text{L.H.S.}$ (Why?)

**Example 8** Find the value of $\cos(\sec^{-1} x + \csc^{-1} x)$, $|x| \geq 1$

**Solution** We have $\cos(\sec^{-1} x + \csc^{-1} x) = \cos(\frac{\pi}{2}) = 0$
