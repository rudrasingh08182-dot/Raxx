We now consider some examples.

**Example 3** Show that
(i) $\sin^{-1} (2x\sqrt{1-x^2}) = 2\sin^{-1} x, \quad -\frac{1}{\sqrt{2}} \le x \le \frac{1}{\sqrt{2}}$
(ii) $\sin^{-1} (2x\sqrt{1-x^2}) = 2\cos^{-1} x, \quad \frac{1}{\sqrt{2}} \le x \le 1$

**Solution**
(i) Let $x = \sin \theta$. Then $\sin^{-1} x = \theta$. We have
$\sin^{-1} (2x\sqrt{1-x^2}) = \sin^{-1} (2\sin \theta \sqrt{1-\sin^2 \theta})$
$= \sin^{-1} (2\sin \theta \cos \theta) = \sin^{-1} (\sin 2\theta) = 2\theta$
$= 2\sin^{-1} x$
(ii) Take $x = \cos \theta$, then proceeding as above, we get, $\sin^{-1} (2x\sqrt{1-x^2}) = 2\cos^{-1} x$

**Example 4** Show that $\tan^{-1} \frac{1}{2} + \tan^{-1} \frac{2}{11} = \tan^{-1} \frac{3}{4}$

**Solution** By property 5 (i), we have
L.H.S. = $\tan^{-1} \frac{1}{2} + \tan^{-1} \frac{2}{11} = \tan^{-1} \left( \frac{\frac{1}{2} + \frac{2}{11}}{1 - \frac{1}{2} \times \frac{2}{11}} \right) = \tan^{-1} \left( \frac{\frac{11+4}{22}}{\frac{22-2}{22}} \right) = \tan^{-1} \frac{15}{20} = \tan^{-1} \frac{3}{4} = R.H.S.$

**Example 5** Express $\tan^{-1} \left( \frac{\cos x}{1-\sin x} \right), -\frac{\pi}{2} < x < \frac{\pi}{2}$ in the simplest form.

**Solution** We write
$\tan^{-1} \left( \frac{\cos^2 \frac{x}{2} - \sin^2 \frac{x}{2}}{\cos^2 \frac{x}{2} + \sin^2 \frac{x}{2} - 2\sin \frac{x}{2} \cos \frac{x}{2}} \right)$
$= \tan^{-1} \left( \frac{(\cos \frac{x}{2} - \sin \frac{x}{2})(\cos \frac{x}{2} + \sin \frac{x}{2})}{(\cos \frac{x}{2} - \sin \frac{x}{2})^2} \right)$
$= \tan^{-1} \left( \frac{\cos \frac{x}{2} + \sin \frac{x}{2}}{\cos \frac{x}{2} - \sin \frac{x}{2}} \right)$
$= \tan^{-1} \left( \frac{1 + \tan \frac{x}{2}}{1 - \tan \frac{x}{2}} \right)$
$= \tan^{-1} \tan \left( \frac{\pi}{4} + \frac{x}{2} \right) = \frac{\pi}{4} + \frac{x}{2}$

Alternatively,
$\tan^{-1} \left( \frac{\cos x}{1-\sin x} \right) = \tan^{-1} \left( \frac{\sin(\frac{\pi}{2}-x)}{1-\cos(\frac{\pi}{2}-x)} \right) = \tan^{-1} \left( \frac{2\sin(\frac{\pi}{4}-\frac{x}{2})\cos(\frac{\pi}{4}-\frac{x}{2})}{2\sin^2(\frac{\pi}{4}-\frac{x}{2})} \right)$
$= \tan^{-1} \cot(\frac{\pi}{4}-\frac{x}{2}) = \tan^{-1} \tan(\frac{\pi}{2} - (\frac{\pi}{4}-\frac{x}{2}))$
$= \tan^{-1} \tan(\frac{\pi}{4} + \frac{x}{2}) = \frac{\pi}{4} + \frac{x}{2}$

**Solution** Let $x = \sec \theta$, then $\sqrt{x^2-1} = \sqrt{\sec^2 \theta - 1} = \tan \theta$
