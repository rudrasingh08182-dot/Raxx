### Some standard integrals

(i) $\int x^n dx = \frac{x^{n+1}}{n+1} + C$, $n \neq -1$. Particularly, $\int dx = x + C$
(ii) $\int \cos x dx = \sin x + C$
(iii) $\int \sin x dx = -\cos x + C$
(iv) $\int \sec^2 x dx = \tan x + C$
(v) $\int \csc^2 x dx = -\cot x + C$
(vi) $\int \sec x \tan x dx = \sec x + C$
(vii) $\int \csc x \cot x dx = -\csc x + C$
(viii) $\int \frac{1}{\sqrt{1-x^2}} dx = \sin^{-1} x + C$
(ix) $\int \frac{1}{\sqrt{1-x^2}} dx = -\cos^{-1} x + C$
(x) $\int \frac{1}{1+x^2} dx = \tan^{-1} x + C$
(xi) $\int \frac{1}{1+x^2} dx = -\cot^{-1} x + C$
(xii) $\int e^x dx = e^x + C$
(xiii) $\int a^x dx = \frac{a^x}{\log a} + C$
(xiv) $\int \frac{1}{x\sqrt{x^2-1}} dx = \sec^{-1} x + C$
(xv) $\int \frac{1}{x\sqrt{x^2-1}} dx = -\csc^{-1} x + C$
(xvi) $\int \frac{1}{x} dx = \log |x| + C$
