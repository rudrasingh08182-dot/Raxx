### 348 MATHEMATICS

#### Miscellaneous Examples

**Example 37:** Find $\int \cos^6 x \sin^6 x dx$
**Solution:** Put $t = 1 + \sin^6 x$, so that $dt = 6 \cos^6 x dx$
Therefore, $\int \cos^6 x \sin^6 x dx = \frac{1}{6} \int t dt = \frac{1}{6} \cdot \frac{t^2}{2} + C = \frac{1}{12} (1 + \sin^6 x)^2 + C$

**Example 38:** Find $\int \frac{x^4 - 1}{x^2} dx$
**Solution:** We have $\int \frac{x^4 - 1}{x^2} dx = \int (x^2 - x^{-2}) dx = \frac{x^3}{3} + \frac{1}{x} + C$

**Example 39:** Find $\int \frac{x^4}{(x-1)(x+1)} dx$
**Solution:** We have $\frac{x^4}{(x-1)(x+1)} = \frac{x^4}{x^2-1} = x^2 + 1 + \frac{1}{x^2-1}$
Now express $\frac{1}{x^2-1} = \frac{A}{x-1} + \frac{B}{x+1}$
