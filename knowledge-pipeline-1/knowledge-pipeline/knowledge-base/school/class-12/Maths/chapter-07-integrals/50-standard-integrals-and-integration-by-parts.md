### Integration by parts
For given functions $f_1$ and $f_2$, we have $\int f_1(x) f_2(x) dx = f_1(x) \int f_2(x) dx - \int \left( f_1'(x) \int f_2(x) dx \right) dx$, i.e., the integral of the product of two functions = first function × integral of the second function – integral of {differential coefficient of the first function × integral of the second function}. Care must be taken in choosing the first function and the second function. Obviously, we must take that function as the second function whose integral is well known to us.

$\int e^x [f(x) + f'(x)] dx = e^x f(x) + C$

### Some special types of integrals
(i) $\int \sqrt{x^2 - a^2} dx = \frac{x}{2} \sqrt{x^2 - a^2} - \frac{a^2}{2} \log |x + \sqrt{x^2 - a^2}| + C$

(ii) $\int \sqrt{x^2 + a^2} dx = \frac{x}{2} \sqrt{x^2 + a^2} + \frac{a^2}{2} \log |x + \sqrt{x^2 + a^2}| + C$

(iii) $\int \sqrt{a^2 - x^2} dx = \frac{x}{2} \sqrt{a^2 - x^2} + \frac{a^2}{2} \sin^{-1} \frac{x}{a} + C$
