One of the notable features of transition elements is the great variety of oxidation states these may show in their compounds. Table 8.3 lists the common oxidation states of the first row transition elements.

| Element | Oxidation States |
| :--- | :--- |
| Sc | +3 |
| Ti | +2, +3, +4 |
| V | +2, +3, +4, +5 |
| Cr | +2, +3, +4, +5, +6 |
| Mn | +2, +3, +4, +5, +6, +7 |
| Fe | +2, +3, +4, +6 |
| Co | +2, +3, +4 |
| Ni | +2, +3, +4 |
| Cu | +1, +2 |
| Zn | +2 |
